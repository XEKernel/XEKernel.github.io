使用流程

四步完成一次生成：从文本到纸张

1

选择字体

从 ttf_library 加载喜欢的字体或自定义 TTF 文件。

2

调整参数

纸张、字号、扰动、纹理、墨水等参数自由组合。

3

预览效果

实时预览渲染结果，反复微调直到满意。

4

导出文件

一键导出为 PNG、PDF 或 SVG 格式。

GUI 之外，CLI 更直接

适合批处理、脚本自动化、远程服务器

基本用法bash
# 从命令行参数生成 PNG
handwrite-cli \
  -t "今天天气真好。" \
  -o "F:/out" \
  -f png \
  -r 2

# 输出 PDF / SVG
handwrite-cli -t "..." -o out -f pdf
批量与预设bash
# 加载预设参数（字体、扰动、纹理等）
handwrite-cli -i essay.txt -p my.conf

# 从文件读取待生成文本列表
handwrite-cli --batch batch.txt

# 支持从剪贴板读取
handwrite-cli --clipboard -o out
