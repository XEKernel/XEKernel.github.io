四·五、C# 工程：结构、名字三处一致、怎么从 CLI 重建

不需要打开编辑器点「项目 → 工具 → C#」——本工程已由 CLI 建好（2026-11-22）：

Chengmai.csproj     ← Sdk="Godot.NET.Sdk/4.7.1"，TargetFramework=net8.0
Chengmai.sln        ← Debug / ExportDebug / ExportRelease 三档
project.godot       ← [dotnet] project/assembly_name="Chengmai"

三处名字必须一致（不一致 = 启动时报 Failed to load project assembly）

位置值
Chengmai.csproj 的 &lt;AssemblyName&gt;Chengmai
.csproj / .sln 的文件名Chengmai.*
project.godot 的 dotnet/project/assembly_nameChengmai

三条硬约束

#约束为什么
1TargetFramework 只能是 net8.0GodotSharp 4.7.1 的 lib/ 只有 net8.0；换版本恢复不到包
2必须 &lt;Compile Remove="bench/" /&gt;**bench/ 是独立工程（各自有入口点、各自编译 core/sim），否则重复类型 + 多入口
3bench/coretest 的 TFM 也必须是 net8.0否则 net10 能编的语法在 Godot 侧编不过：断言全绿但集成失败，最难查

离线恢复

本机 nuget.org 不通，但 Godot 自带离线包源 &amp;lt;Godot&amp;gt;（含 Godot.NET.Sdk.4.7.1 等）， 且 ~/.nuget/packages/godot.net.sdk/4.7.1 已缓存 ⇒ dotnet build 可离线成功。 ⚠ 换机器时若报找不到 Godot.NET.Sdk，把该 nupkgs 目录加成 NuGet 源即可，不要改 TFM。

四·六、本机 Rust / Tauri 环境（2026-11-22 实测，当前是坏的）

参考工程：D:\project\QzoneArchive-main（Rust + Tauri 2，2026-10-31 在本机构建成功过）。

两个坑，按顺序修：

#症状原因修法
1cargo build 报 link: missing operand after '\377\376' / Try 'link --help'Git-Bash 的 /usr/bin/link.exe（coreutils 硬链接工具）抢在 MSVC 链接器前面把 …\VC\Tools\MSVC\&lt;ver&gt;\bin\Hostx64\x64 前置到 PATH；最稳是用 Developer Command Prompt
2LNK1181: 无法打开输入文件 "advapi32.lib"（或 kernel32.lib）Windows SDK 的 Lib/Include 被清空：D:\Windows Kits\10\ 只剩 Catalogs/重装 Windows SDK 本体（注册表 KitsRoot10 还指向 D:\Windows Kits\10\）

另外两条 MSYS2 使用纪律：

  • 给 MSVC 传 /nologo 这种参数会被自动转成路径（F:/Git/nologo）⇒ 用 -nologo，或设 MSYS2_ARG_CONV_EXCL="*"
  • 链接器不认 /d/... 这种 POSIX 路径 ⇒ 一律写 D:/...

可用的事实（不用再验）： MSVC 编译器 14.44.35207 / 14.51.36231 两套都在； rustup 有 gnu 与 msvc 两套工具链，默认 msvc；Tauri 只支持 msvc。

五·五、用户提"新现象"时的处理流程（2026-11-22 定）

开发者原话：「我提到都是一些现象……要把它分到类别里，不然想起来一条加一条会乱。」

不要立刻加一条 F 号。 按四步走（../design/12-china-features.md §二·零）：

  1. 记原话（保留语气，别先翻译成设计术语）
  2. 归类：C1 空间形态 / C2 土地财政 / C3 人口社会 / C4 产业就业 / C5 市政生命周期 /

C6 交通网络 / C7 时间节庆 / C10 文化视觉 / C9 跨系统

  1. 判落点：① 已有条目的参数 ② 已有条目的枚举值 ③ 真要新规则才开新 F
  2. 定批次：B1–B7 / 打磨年 / DLCn（不许"以后""有机会"）

⚠ 三个反例（都是真实发生过的）：

  • 「堵火车」+「铁路切开城市」+「道口」→ 一个区间占用模型，不是三个功能
  • 「地铁有段在地上」→ F23 的 alignment 枚举，不是"高架地铁系统"
  • 「初五商店开门」→ F24 的一张时长表，不是四个节日模式

⚠ 没有"落点"的登记 = 许愿，直接打回。
