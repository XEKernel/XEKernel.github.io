二、发现的问题：theme.json 零引用

$ grep -rn "theme.json" scripts/ tools/
（无输出）
$ grep -c "Color(" scripts/ui/*.gd
about_page 13 / city_backdrop 20 / main_menu 3 / menu_button 5 / settings_page 15 / ui_kit 13

而 config/ui/theme.json 的表头写着：

"_note": "UI 主题。数据驱动：改这个文件就换肤，不用改代码（Mod 深合并覆盖）。"

这条是假的。 而且直接关系到 plan.md 的 B1-4 验收：

B1-4：改 ui/theme.json 的任一色 token，界面颜色跟着变（证明 UI 是数据驱动的，不是硬编码）

按原状去测，必然不过。这是"文档声称 vs 代码现实"最典型的一种漂移： 文件存在、格式正确、注释漂亮，但没有任何一行代码读它。

同一批还发现三套几乎一样的"近白"：(0.94,0.93,0.91) / (0.97,0.95,0.91) / (0.97,0.96,0.94) —— 正是没有 token 体系的必然产物。

三、做了什么

3.1 新建 scripts/ui/ui_style.gd（主题加载器）

  • 读 config/ui/theme.json，缓存；reload() 供调试
  • color("accent") / color_alpha("accent", 0.5) / num("interaction.states.hover.duration_ms") / radius("button") / panel_tint(solidity)
  • 解析 #rrggbb 与 rgba(r,g,b,a)（rgb 是 0–255、a 是 0–1，和 CSS 不同，注释里写清了）
  • 缺 token → push_warning + 用调用方给的 fallback（不静默）

⚠ 踩到一个坑：内部取值函数一开始叫 _get() —— 那是 Object 的虚函数，签名不匹配会让 整个脚本编译失败并连带三个页面全挂。改名 _lookup() 并把这个坑写在注释里。

3.2 把 69 处硬编码颜色接到 token

文件改动
ui_kit.gd删掉 const RED / TEXT / TEXT_SUB / TEXT_FAINT / BTN_BG，全改 Style.*；glass_panel 三个 shader 参数走 theme.material.panel.shader
menu_button.gd三态色（normal/hover/press/border）+ hover/press 时长都读主题
main_menu.gd标题/副标题/提示/版本号
settings_page.gd导航条、分隔线、分类选中态、开关、提示行、行标签、徽标
about_page.gd压暗层（scrim）、标题、职务行、人名、页脚

theme.json 同步补齐 token（值 = 2026-11-20 视觉定稿的实际值，接完线画面不变）， 并新增 _wired 字段逐块标注「真接线 / 只是登记值」——避免下次又出现"注释说能换肤、其实不能"。

3.3 顺手修的两处

  1. 按钮"按下下沉 1px"在主菜单里是失效的：_ready() 里抓 position.y，但按钮在 VBoxContainer 里，

容器是加入之后才排版，抓到的永远是 0。改成 _on_down 里现抓。

  1. 字体加载：原来只按 C:/Windows/Fonts/msyh.ttc 绝对路径找（导出包/别的系统必挂）。

改成「先按已知路径找（保持字形与定稿一致）→ 找不到再用 SystemFont 按字族名解析」。 ⚠ 试过把 SystemFont 放第一位，结果整个界面的字形都变了（Microsoft YaHei UI ≠ Microsoft YaHei）， 所以顺序不能反。

六、诚实的更正：那个"右下被切"的提示，其实没被切

过程里我一度以为主菜单底部提示文字被裁掉一半，于是加了显式 size 并上移 10px。 6 倍放大后发现字形是完整的——"被切"是我自己裁剪截图时把字裁掉了。

10.2 两个必须先验证的点（都写了探针，验完即删）

  1. emoji 能不能渲染 —— 能。Godot 的 TextServer 对缺失字形逐字回退到系统 emoji 字体，

直接出彩色字形（截图见下）。

  1. 悬停提示里的中文会不会变方框 —— 这一步才是关键，因为图标化之后 tooltip 是唯一信息源。

结论：必须把 ThemeDB.fallback_font 设成中文字体，否则就是一片方框。 探针实测输出：道路 / 修路：直路 / 曲线 / 高架 / 跨江桥，两行、中文正常。

  1. 底栏贴着屏幕下沿时提示会不会被裁 —— 不会，Godot 会把它翻到按钮上方。也实测过。

10.3 取舍：面板内部保留文字

竖条上只有图标，但面板展开后的标题与行名保留文字 —— 面板是"内容"不是"按钮"， 行名去掉只剩一排 —，没法读。顶栏同理：数值必须有图标配着，但城市名是标题级信息，保留文字。

10.4 守卫

lint_docs.py 第 10 组：每个可点元素都必须有图标（顶栏项 / 工具组 / 每个子工具 / 每个面板）， 并且每个顶栏项都要有 hud.top.&lt;item&gt;.tip 悬停说明。注入两处空图标实测会报。
