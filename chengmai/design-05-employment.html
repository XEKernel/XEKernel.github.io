05 · 就业与产能：岗位匹配、建材供应链、资源与技改

依据：decisions.md R1（规模）/ R7（R1 可达性→通勤）/ R17（模块化）。
本系统不只算岗位——工业产能、建材供给、资源产出、减燃料增化工都在这里
（12-china-features F60 / F71 / F90，system-boundaries §三-5）。

一、范围

负责不负责
岗位（按用地子类分）与劳动力匹配个人数据（在 population）
工业产能（M0–M4，含 M1b 化工）通勤路径（在 traffic）
建材供应链：需求、产能、进口、短缺建造本身（在 zoning）
资源开采：储量、年产、枯竭资源点的地图数据（在 B1 地图契约）
减燃料增化工技改（F90）化工的价格（在 finance）
高技能比例（轨二评级用）评级本身（在 core 年边界）

二、岗位分类（跟用地子类对齐）

用地岗位类型技能档备注
M0 资源开采矿工/钻工低人均产出高、就业少、会枯竭
M1 建材建材工人低产能决定全城建设速度
M1b 化工化工操作/技术中可技改，附加值随化工占比上升
M2 消费品普工低就业密集
M3 装备电子技工中—
M3h 高新研发高需通信覆盖 + 高技能人口
M4 物流仓储司机/仓管低需贴近快速路
B 商业办公服务业/白领中–高高薪岗位的主要来源之一
A 公共服务教师/医护高services 的实际岗位

⚠ 技能档只有三档（低/中/高）。这是"高薪岗位占比"（轨二评级）的计算基础， 不需要更细的划分——更细只会增加平衡难度。

二·五、岗位匹配：供需怎么对上（2026-11-17 补）

系统间接合的空白：population 给劳动力，employment 给岗位，谁负责撮合？
答案：本系统只出"岗位空缺"，撮合在 population（见 04 §3.5.2）。
这里只定义岗位怎么产生、怎么消失。

2.5.1 岗位从建筑来

建筑类型岗位数公式
M0 资源开采min(年产能, 储量) / 人均产出，枯竭即归零
M1 / M1b建筑面积 × 每 m² 岗位密度（化工更低，因为自动化）
M2建筑面积 × 最高密度（劳动密集）
M3 / M3h建筑面积 × 低密度，但技能档要求高
B 商业办公建筑面积 × 中等密度
A 公共服务由 services 反推（学校需要多少教师）

⚠ 岗位不随人口自动增加：只有建成建筑才产生岗位。 "人口涨了岗位自然多"是错的——那正是"失业"要解决的问题。

2.5.2 岗位消失的三种情况

情况后果
建筑废弃 / 拆除岗位消失 → 该处就业者全部失业
资源枯竭（M0）同上，且不可恢复
技改停产期（F90）岗位临时消失 6–12 月，之后恢复

⚠ 技改停产期的失业是"可预期的"：玩家自己选的，应提前显示"停产期间约 X 人失业"。

2.5.3 通勤上限反过来限制建厂

⚠ 这是 employment 与 traffic 的隐藏耦合： population 的通勤搜索上限是 27 个小区（04 §3.5.2）。 所以建在远郊的工厂，可能招不到人——因为没人愿意通勤那么远。

⇒ 玩家的真实约束是："建厂"与"修路/建住宅"必须配套。 这比"随便建厂就有人来"真实得多，也解释了产业新城为什么常常是空城。

三、建材供应链（F60，本系统最复杂的部分）

3.1 链路

需求侧：zoning 报"在建面积 × 单位消耗" → zoning.material_demand
供给侧：M1 产能（水泥/钢材）+ 进口补足 → employment.material_supply
缺口 → 进口，成本 = 基础价 × (1 + 距离系数)，并占用对外运力
总量不足 → 全城在建工地按比例减速（塔吊停转）

3.2 三条约束

#约束理由
1不做逐车物流否则变成《运输模拟器》。只做月度供需平衡 + 运力占用标量
2zoning 读上月产能（滞后一期）否则要改 Tick 顺序（system-boundaries §三-3）
3进口永远可得，但越来越贵保证城市不会因为"没建材"完全停死，只是变慢变穷

⚠ 第 3 条很重要：完全断供会让游戏变成"必须建水泥厂否则卡死"， 那就不是规划游戏了。用价格调节，不用硬卡。

3.3 砂石：建材的上游（F71 矿石）

砂石场（M0，占资源点）→ 水泥厂（M1）→ 工地

砂石产能不足 → 水泥产能受限（即使水泥厂建够了）→ 工地减速。 ⚠ 真实原型：2018–2020 河砂禁采导致砂石暴涨、多地停工（12-china-features §11.2）。

四、资源开采与技改（F71 / F90）

4.1 资源产出

项规则
产量min(年产能, 剩余储量)，月度摊分
储量每月递减，按品位加权（高品位先采）
枯竭储量为 0 → 停产，M0 岗位消失
沉陷采煤每单位累积沉陷风险，越阈值 → 周边 parcel 不能新建、地价腰斩（F73）

4.2 减燃料增化工技改（F90）

项规则
触发玩家主动发起，不是自动
成本一次性投资 + 停产期 6–12 个月
效果产出结构从「燃料 70 %/化工 30 %」切到「化工 60 %+」
后续随年份与技术继续下移（2050 约 40/60，2100 约 10/90）

⚠ 不技改的惩罚是渐进的：燃料需求随电动化下降 → 同样的产能越来越不值钱。 不是某一天突然崩，而是一年比一年难受。 这才是真实的资源型城市衰败方式。

四·五、产业升级与招商：条件驱动，不是点击解锁（2026-11-18 新增）

⚠ 本节是 2026-11-18 扫描发现的空白：F42 开发区招商 / F90 技改 都登记了，
但"产业怎么从低端走到高端"从来没写过。而这是"城市怎么长大"的核心。

4.5.1 产业阶梯（六级，不是"高低两档"）

级子类典型岗位密度技能要求税收
0M0资源开采极低低低
1M1初加工 / 建材中低低
2M1b化工低中中
3M2劳动密集制造最高低低（但就业多）
4M3先进制造中中中
5M3h高新 / 电子低高高
侧M4物流仓储低低低
侧B / CBD服务业 / 办公中–高中–高最高

⚠ 不是"越低越差"：M2 单位面积岗位最多，解决就业最有效，但税收低。 玩家会在"就业"和"税收"之间反复权衡——这是设计意图，不是缺陷。

4.5.2 ⭐ 升级是"条件满足后自动发生"，不是"付费解锁"

错误做法（不要做）：花 ¥500 万 → M2 变 M3。 正确做法：企业自己评估条件，满足就升级，不满足就搬走。

五条升级条件（全部要满足）

#条件数据来源
1技能劳动力够该片区高技能人口 / 岗位需求 ≥ 1.0
2基础设施够电力容量富余 ≥ 30 %、通信覆盖、供水稳定
3交通可达accessibility ≥ 阈值、货运通道通
4产业链配套建材/零部件本地可得（material_chain）
5地价/租金可承受租金 ≤ 该产业毛利率的 30 %

⚠ 第 1 条是最容易卡住的：没有高技能人口，产业升不上去。 而高技能人口来自教育（07-services 的学校）——这条把教育和产业接上了。

⚠ 第 5 条制造真实矛盾：地价涨 → 低端产业待不住 → 被迫外迁。 这就是"腾笼换鸟"，也是老城区产业空心化的来源。

4.5.3 招商（F42 开发区）：补贴有用，但不是万能

步骤机制
1玩家划开发区（M 类 + 政策标签）
2给招商补贴（13-player-loop §十三 的旋钮，0–500 万/企业）
3企业按五条条件打分，补贴只是其中一项
4分数达标 → 迁入；不达标 → 补贴再多也不来

⚠ 补贴的边际效用递减：补贴 ×2，吸引企业数只增约 30 %。 ⚠ 企业会挑地方：同样补贴，交通好、劳动力足的地方先满。

⭐ 这防止"砸钱就能建产业"的简单解法，也解释了真实的开发区为什么有的活、有的死。

4.5.4 企业迁出：和升级对称的另一半

触发说明
成本上升地价/工资涨到毛利率 30 % 以上
交通恶化avg_commute_s 上升 → 招不到人
政策恶化税率过高、补贴取消
资源枯竭M0 特有（§四）

⚠ 迁出不是瞬间的：从"开始亏损"到"搬走"给 12–24 月缓冲期， 期间产能下降、岗位减少——玩家有反应时间（符合 13-player-loop §五 的预警原则）。

4.5.5 技能档怎么产生：完整答案在 07-services §三·五

技能来自教育阶梯，不是"建学校就涨"：

路径技能档
初中及以下low
职业学校（普职分流 50 %）low_mid（技工）
高中毕业未升学mid_low
大专 / 高职mid
本科（同龄人 ~12 %）high

⚠ ⭐ 关键：本科率高不等于好 —— 把本科率调到 50 %，技工就没了， M2/M3 招不满人（07-services SV17 断言）。

⚠ 这条让"建学校"有了长期回报，而不只是学区房溢价—— 学区房是短期套利，技能人口是长期税基。 两者都是真的。

4.5.6 验收点

#断言
EM14技能人口不足时，M2 无法升级为 M3（补贴再多也不行）
EM15建成学校 → 20 年后该片区高技能人口比例上升，产业开始升级
EM16地价涨到阈值后，低端产业开始外迁（腾笼换鸟）
EM17企业迁出有 12–24 月缓冲期，不是瞬间消失
EM18补贴翻倍，吸引企业数只增约 30 %（边际递减）

⚠ EM14 是本节的核心：如果"砸钱就能升级"，整个产业系统就退化成了数值滑块。

五、数据契约

5.1 结构

结构字段上限
job_slotparcel_id(u32) subtype(u8) skill(u8) filled(u32) capacity(u32)≤ 30 万
industryparcel_id(u32) subtype(u8) output(u32) fuel_ratio(u8) upgrading(bool)≤ 5 万
resource_sitecell_x(u16) cell_y(u16) kind(u8) reserve(u32) grade(u8) annual_cap(u32)≤ 5,000

⚠ job_slot 的 30 万上限待核（2026-11-21 标）：100 万人口按 50–60 % 就业率需要 50–60 万岗位。 两种解释二选一，必须在 B4 前定： ① job_slot 是聚合槽位（capacity 为该槽位可容纳人数，一个槽位 = 一栋楼的岗位包）⇒ 30 万够； ② job_slot 是逐岗位 ⇒ 上限必须提到 60 万，且 filled(u32) 的数组会涨到 240 MB 量级。 当前文档没有写清是哪一种，这是 11-scale §6.1 内存表之外的一块隐性开销。

⚠ 资源点是地图数据（B1 地形契约的一部分），employment 只读不写储量以外的东西。

六、验收点

#断言怎么测
EM1岗位空缺 > 0 → population 净迁移为正（联动 P3）探针对照
EM2拆掉全部 M1 → 建材缺口 > 0，进口成本上升，且在建工地减速探针三步对照
EM3砂石产能为 0 时，即使水泥厂充足，水泥产出也受限探针断言
EM4资源点采完 → M0 岗位归零，该 parcel 建筑废弃探针快进
EM5采煤累积到阈值 → 周边 parcel subsidence 生效，不能新建探针断言
EM6技改后 fuel_ratio 显著下降，且停产期产出为 0探针断言
EM7不技改的化工城市：2050 年同产能的收入明显低于技改城市两支对照快进
EM8employment 不写 zoning（只在 bus 上写自己的 key）check_contract
EM9存档 → 读档后储量、fuel_ratio、filled 完全一致探针比对
EM105 万工业 + 5000 资源点下月结 ≤ 300 msprobe_tick
EM11人口翻倍不会让岗位翻倍（岗位只来自建筑）探针两组对照
EM12远郊工厂招不满人（通勤超 27 个小区），近城同规模工厂能招满探针三组对照
EM13技改停产期内该厂岗位归零，结束后恢复探针断点

⚠ EM2 是 F60 存在的唯一证据：如果拆了水泥厂工地照跑，那建材供应链就是白做。 ⚠ EM7 是"减燃料增化工"这个机制的全部意义：不做技改的城市必须真的吃亏， 否则玩家没有理由选择它。

七、待定

  1. M3h 的通信门槛具体怎么判 —— 覆盖面积占比还是容量？建议容量
  2. 进口是否要走"港口/铁路枢纽" —— 会大幅增加真实感，但也增加复杂度，建议只做"对外通道"标量
  3. 沉陷区的治理机制 —— 花钱恢复，但恢复后能否重建？建议可以，否则地图会被永久毁掉
