一、先纠正一个前提：体积不是硬约束

开发者原话：「我要追求模拟的真实，所以大小肯定不可避免要涨上来，CS1 当初都有 4GB，现在都 15GB 了。」

本文件上一版写了"≈300 MB 已接近独立游戏上限"——这条撤回。参照：CS1 本体 4 GB，今天（含 DLC）15 GB。 模拟类游戏的体积上限由硬盘决定，不由"独立游戏"这个身份决定。

正确做法不是"省体积"，而是 ① 分级精度 ② 可选安装 ③ 加载策略（见 §5.3）：

做法效果
同一资产四档 LOD（不是四套模型）磁盘一份，运行时按设置选
高精度包作为可选下载（Steam DLC/分卷）低配玩家只装基础包
按需流式加载（按 2 km 瓦片）内存占用与硬盘体积解耦

⚠ 与 11-scale 的关系：那里的预算是显存/帧时间，不是硬盘。硬盘可以大方，显存不能。

二、为什么要扩到 257 类（而不是 26 类）

城市天际线的可识别性来自少数强特征物：烟囱、冷却塔、高铁站、体育场、寺庙、牌坊、塔吊。 26 类能跑通玩法，但截图发出去会像"通用城市"。97 类补齐四块原本完全空白的东西：

原本空白现在补了
医疗与民政（一个都没有）社区诊所 / 区级医院 / 三甲 / 养老院 / 福利院
行政与治安（只有 civic 模型，谱系里没登记）派出所 / 消防站 / 法院 / 街道办 / 邮政驿站
文保与宗教（完全没有）寺庙 / 教堂 / 清真寺 / 牌坊 / 骑楼 / 城墙
构筑物（烟囱冷却塔这些"不是房子"的）烟囱 / 冷却塔 / 储罐 / 筒仓 / 水塔 / 龙门吊 / 输电塔

3.9.1 隧道：只做洞门，内景推迟（2026-11-23）

开发者：「隧道内景暂时不做，推到 DLC 或者打磨年。」
做不做
洞门（端墙/翼墙/遮光棚）、限高架、洞门外立面贴图洞内路面、照明灯带、通风风机、横通道、内壁

⚠ 理由：内景只在"相机进入隧道"时可见，而 11-scale 的相机默认在高空/斜俯视； 做内景等于为 1% 的视角做 100% 的工作量。DLC 或打磨年再补，接口先留（rd_tunnel 的 interior 字段留空）。

3.9.2 ⭐ 组合型设施：机场 / 高铁站 / 地铁站不是"一栋楼"

开发者：「有的建筑是多种组合，比如机场还有地铁站高铁站等，有公共交通组合型建筑。」

这不是新 archetype，而是拼装规则。 机制已经在 10-presentation §4.5.2（config/assets/compose.json）定好了： 一份「允许集」描述主体/屋顶/基座/附着件，生成器按 era + 相邻条件选。

⚠ T5 的合批收益极大：所有建筑共用一个材质 ⇒ 整个城市变成极少数 draw call， 这也是为什么"白模档"能救老机器——不是因为它简单，是因为它能合批。

七、裁剪原则（什么时候可以不做）

新增/保留一类，必须过这四问（第四问是硬门槛）：

  1. 玩家一局里会看到它 3 次以上吗？ 会 → 做；不会 → 用最接近的类替代或程序化。
  2. 能否用"变体"代替"新类"？ 例：dept_store 与 mall 体量相近，能用同一模型改招牌就不必两类。
  3. 它只是背景吗？ 背景用 LOD3 或贴片（billboard）即可，不进 LOD0 预算。
  4. ⭐ 它能不能指向一条"中国特色"的现实依据？ —— 台账编号（12-china-features F 编号）、

国标门类（03-zoning §2.3 的 M0–M4）、或一个真实案例（镇海炼化、大庆油田、寿光大棚）。 答不出来就不进清单。 这条防的是"通用城市模拟套皮"：能想到的建筑无穷多， 但只有中国现实里成立的那部分才该出现在这游戏里。

⚠ 反过来还有一条：地标类不许裁（高铁站、体育场、寺庙、烟囱）。它们是"这是中国城市"的证据， 砍掉之后整个画面就会退回"通用欧美城市"。

八、招牌：中文是内容，不是 UI

开发者原话：「店铺的招牌就用中文设计几个，这也是中国特色，翻译的话就没味了。」

8.1 三条规则

#规则理由
1招牌文字不翻译（除少数全国连锁）中文招牌是中国街景的构成要素，翻译成 "Barber Shop" 之后街就不像中国街了
2至少 40–60 组不同文字，避免一条街重复反复出现"超市超市超市"比空白更假
3参差比文字更重要大小/颜色/位置高低不齐，才是真实街景（14-model-prompts §5.3）

8.3 多语言玩家怎么办

  • 街道招牌保持中文：玩家不需要"读懂"，需要"看起来对"（和现实里外国人看中国街道一样）
  • 只有需要识别的品牌（全国连锁：银行、快餐、快递）才提供本地化版本，且只换文字不换形制
  • ⚠ UI 文案照常八语（R20），但招牌属于美术资产，不进 i18n/

8.4 技术上

  • 招牌是图集里的一块（10-presentation §三）：一张 4096² 图集放 32–64 个招牌
  • 每个招牌有两张：白天版 + 夜间发光版（或一个自发光通道）
  • 文字烘焙进贴图，不用字体渲染（字体要授权、多语言字形、性能都不划算）
