07 · 公共服务与市政：学区（R3）+ 水电气网络（容量法）

依据：decisions.md R7（R3 学区用最小实现）/ R9（7 系统）/R4（规范年代）/R12（DLC）。
⚠ 基础设施已拆出本系统（decisions.md R15，2026-11-15）。
电 / 水 / 污水 / 雨水 / 通信 / 燃气 / 垃圾 全部归新的第 8 个系统 utility。
本系统只做半径型公共服务：学校 / 菜市场 / 公园。
⚠ 本文件 §四 仍保留基础设施的设计内容（因为写在这里时还没拆），
但实现落点是 scripts/sim/utility/，不是本目录。

  • 三、教育服务（R3 的载体，最小实现）
  • 三·五、教育阶梯与技能产出：普职分流决定产业上限（2026-11-18 新增）
  • 三·六、补习班与放学小吃摊：中国街头最真实的两种"非正式设施"（2026-11-18）

一、范围

负责不负责
教育服务：学校评分（R3）、学位容量、覆盖学区对地价的影响（在 06-finance-land，A5）
电力网络：杆塔（四级）+ 链路 + 容量衰减（F52）水/气/通信的管网几何（埋地，不画）
水 / 燃气 / 通信：容量 + 覆盖半径（F52）医院、文化、体育（推 DLC / 打磨年）
容量不足的后果（建筑无法生长 / 降级）污染（DLC1，zoning.pollution 预留；R27）

二、两类服务，两种算法（这是本篇最关键的区分）

类型代表覆盖方式计算
半径型学校、医院、菜市场以设施为圆心，半径衰减coverage = Σ f(dist)，与容量无关
网络型水、电、燃气、网络容量 + 覆盖半径需求 ≤ 容量 且 距离 ≤ 半径

⚠ 这两类不能混成一个"服务水平"数字。半径型不够是"不方便"，网络型不够是"楼长不出来 / 直接荒废"。 后者是硬门槛，前者是软影响。

三、教育服务（R3 的载体，最小实现）

3.1 学校评分（一个标量，不建三本账）

school_score = 投入水平 × exp(-dist / 500m) × 学位余量系数
因子来源
投入水平财政拨款 / 学生数（finance 给）
距离衰减500 m 半径，exp 衰减（A5 断言的判据就是这个）
学位余量(容量 − 在校生) / 容量，为负则挤爆

⚠ v1 的教训：services 曾写成「教师-生源-设施」三本账，11 个文件，最后没人算得清。 本项目只允许这一个标量公式。谁想加第二个因子，先来 decisions.md 提一条。

3.2 自我强化（R3 的正反馈）

school_score ↑ → 周边地价 ↑ → 生源家庭收入 ↑ → 财政拨款 ↑ → school_score ↑

⚠ 这个正反馈必须有上限与衰减，否则会指数爆炸（好学区吃满全城）。 建议：投入水平 取对数，或对 school_score 设顶格。

3.3 寒暑假（F25）⚠ 2026-11-18 修正：不清零

⚠ 原写"寒暑假学生通勤 OD 归零"。这是错的。
用户指出：「假期时间还是能看到学生背书包去补课等。」
学期内寒暑假
purpose=school（上下学）正常归零 ✅
purpose=tutoring（补习）傍晚 + 周末⭐ 不归零，约为学期的 15–25 %
学校服务计分正常服务暂停（评分值保留）

⭐ 修正的意义：如果寒暑假学生 OD 全清，假期街道上就没有背书包的孩子—— 这在中国的城市里是不可能的。补习班把"假期"变成了"另一种学期"。

⚠ A5 断言（学区 12 月内周边地价 +10%）必须在学期内测，否则测不出通勤变化。

三·五、教育阶梯与技能产出：普职分流决定产业上限（2026-11-18 新增）

用户：「教育这方面我国现在是幼儿园，小学，初中，高中（或者没考上高中上职业学校，或直接打工），
大学（或没考上走大专或者毕业直接工作），这样从这些出来的学校的人可以去不同的产业等级。」

这是"技能人口从哪来"的完整答案，也是 05-employment §4.5.2 五条升级条件里第 1 条的来源。

3.5.1 四段阶梯（不是六段）

段年龄学制学校出口
学前3–53 年幼儿园—
义务6–146 + 3 年小学 + 初中⭐ 中考分流
高中段15–173 年普通高中 / 职业学校高考 / 直接就业
高等18–213–4 年本科 / 大专（高职）就业

⚠ 义务段是强制的：小学 + 初中必须有足够学位，否则计入满意度惩罚（这是硬约束， 不是"可选设施"）。现实中"入学难"是家长最敏感的事。

3.5.2 ⭐ 中考普职分流：中国最独特的机制

这是整个教育系统的分水岭，也是产业结构的决定因素。

初中毕业（约 14 岁）
   ├─ 约 50 %  → 普通高中 → 高考
   └─ 约 50 %  → 职业学校（中专/技校/职高）→ 技术工人
项值
普职比（普高 : 职校）默认 5 : 5（政策目标，可配置）
现实差异各地 4:6 到 6:4 不等

⚠ 为什么这条重要：技术工人（low-mid 技能）是制造业的脊梁， 而普职分流是技工的唯一来源。

3.5.3 五条路径 → 四档技能

路径同龄人占比技能档主要去向
初中及以下（辍学务工）低lowM0 / M1 / M2
职业学校~40–50 %low-mid（技工）⭐ M2 / M3 主力
高中毕业未升学少mid-low服务业 / M2
大专 / 高职~15 %midM1b / M3 / 服务
本科及以上~12 %highM3h / CBD / 研发

⚠ 本科率只有 12 % 左右（按同龄人算），这是中国的真实水平。 如果玩家把本科率调到 50 %，技工就会严重短缺——这不是数值问题，是结构问题。

3.5.4 ⭐ 玩家的决策：普职比，一个真实的两难

这是本节最重要的机制：vocational_ratio 可以调，但两头都有代价。

玩家调向短期长期
提高普高率（更多大学生）✅ 家长满意度↑❌ 技工短缺 → 制造业招不到人
提高职校率（更多技工）❌ 家长满意度↓（现实中的"普职分流焦虑"）✅ 制造业有充足技工

⭐ 这正是中国真实的政策困境：普职分流被家长抵触，但制造业需要技工。 玩家必须在"民意"和"产业"之间选。

⚠ 满意度影响要真实但不能过重：普职比从 5:5 调到 3:7，满意度下降约 3–5 个百分点 （不足以触发崩盘，但会持续拖累迁移）。

3.5.5 ⚠ 关键简化：不跟踪个体教育路径

如果跟踪每个学生的 15 年路径（1000 万人口 × 15 年），开销不可接受。

用"流动模型"代替：

每级学位容量 = Σ(该级所有学校的容量)
入学率 = min(1, 学位容量 / 适龄人口)
升学率 = 按普职比 / 高考录取率分配
产出 = 每年毕业生 × 各档比例 → 累加到技能人口池

⚠ 只算"池子的流入流出"，不算每个人的经历。 这与 04-population 的三层结构一致（citizen 只存当前技能档，不存学历历史）。

3.5.6 ⭐ 学校的两种：配建 vs 重点

1000 万人口需要 600+ 所小学（少儿 170 万 ÷ 6 年学制，按 24 班 × 45 人算）。 不可能让玩家手动放 600 所。

类型谁建作用
配建学校住宅小区自动配建（中国规定：小区必须配建小学）提供基础学位，无学区溢价
重点学校玩家手动点放有名字、有评分、产生学区房溢价

⭐ 这个划分解决了三个问题： ① 玩家不必手动放 600 所学校； ② 学区房只来自少数重点学校，符合现实（不是所有小学都涨房价）； ③ A5 断言（学区 12 月地价 +10%）有明确的载体——只对重点学校成立。

⚠ 配建学校也占用地：小区规划时要留出教育用地，否则该小区不能交付。

3.5.7 验收点

本节断言并入 §六 主验收表（SV15–SV19）。 ⚠ SV17 是本节的核心：它证明"教育结构决定产业可能"，而不是"教育越多越好"。

三·六、补习班与放学小吃摊：中国街头最真实的两种"非正式设施"（2026-11-18）

用户：「假期时间还是能看到学生背书包去补课等，当然不是所有的学生，
补课班地点有的在小区里面，有的是租的门面，有的就是专门的机构，
以及放学时学校门口必有小吃摊。」

这两样都是不占正规用地、但有真实人流的东西。它们的存在让城市"像真的"。

3.6.1 补习班：三种形态，正好对应三种用地

形态用地特征合规性
小区内"住改商"R（住宅）无招牌、隐蔽、家长口碑传播⚠ 违规（改住宅用途）
租门面B1（商业）临街、有招牌、小班✅ 合规（需办学许可）
专门机构B3（教育科研）独立体量、大班、连锁✅ 合规

⭐ 这个映射是自然的：补习班不需要新的用地类型，它就是"住宅/商业里的一类租户"。

⚠ 不做单独的 building 实体：补习班不是一个建筑，是建筑里的一个占用。 用 parcel.tenant 上的一个标志位即可（has_tutoring）。

3.6.2 补习班产生的三件事

产出说明
学生 OD（purpose=tutoring）⭐ 傍晚（17–21 点）+ 周末全天 + 寒暑假
住宅区轻微人流与噪音集中在放学后与周末
⚠ "住改商"违规影响轻微"市容/秩序"指标，不是硬失败

⚠ purpose=tutoring 的时段分布与 school 完全不同：

  • school：早高峰（去）+ 下午（回）
  • tutoring：傍晚（去）+ 夜间（回）+ 周末高峰

⇒ 需要单列一类 purpose，不能并进 school（否则时段特征会被平均掉）。

3.6.3 ⭐ 一个真实的社会张力（可选机制）

项说明
家长对补习的需求与"学校评分"负相关（学校差 → 补习多）
"双减"政策玩家可开关：关闭补习 → 满意度短期上升，但长期学区房溢价更高（因为只剩重点校一条路）

⚠ 这条推打磨年：机制有价值，但不是闭环必需。 ⚠ 但视觉上必须保留：即使政策关闭，小区里偷偷补课的小孩是中国街头的真实风景。

3.6.4 放学小吃摊：纯视觉，但必须有

放学的学校门口必有小吃摊。 这是中国城市最强烈的日常符号之一。

项处理
sim 状态不需要（摊贩是临时的，不占永久用地）
出现条件view 层判断：附近 300 m 内有学校 + 当前时段 = 放学（15:30–18:00）
表现3–8 个小摊位沿人行道排开（props，非建筑）
交通影响⚠ 占道，通行能力 −5 %（轻微，与 F41 占道停车同类）
雨天减少或消失

⭐ 用 view 层做，不进 sim：因为它是纯表现，且"是否出现"可由已有数据推导 （学校位置 + 时段），不需要额外状态。

⚠ 这也是宪法 L2 的正面例子：表现层可以读 sim 的公开数据自己决定画什么， 但不许写回去。

3.6.5 验收点

本节断言并入 §六 主验收表（SV20–SV23）。 ⚠ SV23 是宪法 L2 的守门断言：摊贩若出现在 sim 里，说明表现层越界了。

四、市政基础设施：按"看不看得见"分两类

⚠ 2026-11-15 修正。 我原先的方案是"全部用容量法、不建管网"，
用户当场指出：**「水路管路也是重要的东西，尤其是电网，中国电网的电塔有多种，
并且能够承载不同的容量（老城区常见）」**。
这个反馈推翻了一半：问题在于我把它当成一类东西，而它们不是。

4.0 分界线：可见的才值得画

设施玩家看得见吗做法理由
电力✅ 看得见（电线杆、铁塔、变压器、架空线）真实网络：杆塔 + 连线 + 分层容量中国县城与老城区的"蜘蛛网"是极强识别符号，画出来就是景观
供水❌ 埋地下容量法画了也看不见，只有烦
燃气❌ 埋地下容量法同上
通信❌ 埋地下（基站在楼顶）容量法同上

⚠ 这条原则比"简化"更重要：管网的价值不取决于它多真实，而取决于玩家能不能看见自己在做什么。 CS1 的水管被玩家讨厌，不是因为它复杂，是因为它埋在地下，玩家画完就再也看不见了。

4.1 电力网络（本篇最重的一块）

四级杆塔（对应不同容量与时代）

等级形态容量占地出现年代视觉
0 低压杆水泥杆 / 木杆小（一户到一栋）极小老城区、村庄密集、杂乱、"蜘蛛网"
1 中压杆水泥杆 + 变压器台中（一个街区）小县城老城一根杆挂一个变压器箱
2 高压铁塔角钢塔大（一个片区）中（需走廊）城市边缘高、醒目，天际线识别物
3 超高压大型铁塔极大（全城）大（需保护走廊）城外一般不进城

⚠ 等级 0 与 1 是"老城区常见"的那两种（用户原话）。它们的特点是低矮、密集、沿街挂， 所以在老城画面里会形成明显的"电线网"层理，跟新区的地埋电缆形成对比。

网络规则（三条）

#规则
1杆塔必须连成网：每个杆塔沿道路布点，与相邻杆塔连线；孤立杆塔不供电
2容量沿链路衰减：从变电站（源头）向外，每级杆塔的可用容量递减；超出即 shortage
3老城区可"降级改造"：把等级 0/1 换成地埋电缆（等级提升、视觉变干净），但要花钱且施工期扰民

⚠ 规则 3 是一个很好的决策点：老城电网改造 = 花钱 + 施工期拥堵，换来"地价涨 + 视觉变好"。 这是真实的城市更新题材，而"画水管"永远给不了这个。

4.2 供水：一条链，不是一滴水

⚠ 2026-11-15 二次修正。 用户补了一句：「水要建抽水站、泵房等，还有污水处理厂」。
我原来写"水厂 + 3 km 半径"，把它当成一个点——这是错的：供水有地理约束和级联依赖。
抽水站（必须临水体）→ 净水厂 → 泵房（远距离加压）→ 覆盖区
环节约束缺失后果
抽水站必须临水体（河 / 湖 / 水库），且不能在水体下游污染区无取水点 → 全城无水
净水厂需 U 类用地，容量决定全城上限处理能力不足 → 按缺口限供
泵房离净水厂 > 2 km 时必须建，否则远端水压不足远端地块 power_ok 之外的第二个门槛

⚠ 这条链的意义：城市不能"随便哪里建个水厂就通水"，必须先有水源。 这让地图上的水体从"装饰"变成战略资源——也解释了为什么中国城市几乎都临水而建。

4.3 污水：必须在下游

污水收集（简化：按覆盖计）→ 污水处理厂（必须临水体下游）→ 排放
规则后果
污水厂必须在水体下游（用流向判定）上游建厂 → 下游污染 → 扣地价
处理率 = 处理能力 / 污水产生量处理率 < 100% → 水体污染值上升（数值在 DLC1，基础版只扣地价；R27）

⚠ 基础版不做污染扩散（DLC1，R27），只把"处理率不足"折算成河岸地块的地价扣减。 这样一个数字就能表达"污染"，不必先做扩散模型。

4.4 通信：基站是可见的

用户原话：「通信需要建通信基站等」。基站看得见，所以它跟电线杆一样，不能只做容量法。
机房（`U` 类，一个片区一个）→ 基站 → 覆盖
基站类型覆盖出现位置可见性
楼顶站300–500 m高层楼顶小天线，远景几乎不可见
地面塔800–1200 m空地、路边可见，是天际线元素
微站100–200 m商圈、密集区灯杆/墙面小盒

⚠ 基础版的简化：只做"机房 + 覆盖半径"，把基站当作机房的视觉表现（自动沿覆盖区布点， 玩家不逐个摆）。这样保留视觉，不增加操作量。

⚠ 燃气仍用容量法（埋地，不可见），不升级成链。

4.5 为什么电力不能也简化成容量法

因为电塔是城市天际线的一部分。老城区一根水泥杆挂着三个变压器、电线横过窄巷—— 这是中国县城最有辨识度的画面之一，跟"招牌 + 空调外机 + 晾衣杆"是同一层的东西。

而水厂只是一个点（utility_plant 原型），它不需要网络。
